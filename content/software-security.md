## Approved software

SCU maintains a list of approved software that has been tested for security and compatibility. Check the software centre or contact Technology Services before installing new software on a university device.

## Automatic updates

University-managed devices receive security updates automatically. Do not defer updates for more than 48 hours. Restart your device when prompted.

## Requesting new software

If you need software that is not on the approved list, submit a request through the Technology Services Service Desk. Include:

- What the software does
- Why you need it
- Whether it is free or requires a licence
- Whether it connects to external services

## Personal devices

Do not install work-related software on personal devices unless it is specifically approved (e.g. Microsoft 365 apps, MFA apps). Use the browser version where possible.

## Software to avoid

- Peer-to-peer file sharing (BitTorrent, etc.)
- Cracked or pirated software
- Browser extensions from unknown sources
- Remote access tools (TeamViewer, AnyDesk) unless approved
